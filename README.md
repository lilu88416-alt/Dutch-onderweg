# Onderweg

Een Nederlandse gesprekspartner voor in de auto. 一个开车路上练荷兰语的网页：你说荷兰语，Claude 用短句回答并提问；听不懂点「拆解」，它用中文逐段解释；每轮的新词自动存进词库，下次开场先复习。

Alles draait in de browser van je telefoon. De API-sleutel en de woordenlijst staan alleen op je eigen telefoon.

## Eerste keer

1. Open de pagina op je iPhone in **Safari** (niet in Chrome: daar werkt spraakherkenning op iOS niet).
2. Tik ⚙ → vul je **Anthropic API key** in (maak er een op console.anthropic.com) → Opslaan.
3. Tik **Begin het gesprek**. Safari vraagt één keer om de microfoon: kies *Toestaan*.
   Blijft de microfoon geblokkeerd: tik op **AA** in de adresbalk → Website-instellingen → Microfoon → Toestaan.
4. Deel → **Zet op beginscherm**, dan opent hij als een app.

## Gebruik

- **Grote knop (midden)**: tik, spreek Nederlands, stop met praten; de zin wordt vanzelf verstuurd.
- **中文** (links): tik en zeg het in het Chinees, bijvoorbeeld 「我想问这个词什么意思」.
- **拆解** (rechts): Claude legt zijn vorige zin stuk voor stuk uit in het Chinees en vraagt het dan eenvoudiger.
- **Herhaal langzaam**: de laatste zin nog een keer, trager.
- **Stop**: sluit af, leest de nieuwe woorden van vandaag voor en bewaart de sessie.
- **≡ Woorden**: de woordenlijst met herhaling (✓ ken ik / ✗ nog niet). Woorden komen terug na 1, 3, 7, 14 en 30 dagen.

Thema wisselt per dag: werk (universiteit) / dagelijks leven. In ⚙ kun je dit vastzetten.

## Veiligheid

Alleen tikken als de auto stilstaat of de telefoon in een houder zit. Per beurt is één tik nodig; volledig handsfree is in Safari niet mogelijk.

## Backup

⚙ → **Exporteer** kopieert de woordenlijst als JSON naar het klembord. Plak het in Notities. **Importeer** voegt een eerdere export samen met de huidige lijst.
